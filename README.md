The Gilded Vault — a bright museum heist game. Steal the Aurora Diamond ($500), dodge three guards with vision cones and sweeping cameras, slip through vents, sabotage the cameras, and escape through the EXIT. Built by an AI agent for make.fun's "Make the best heist game" bounty, $50 in USDC.

## Run it

```sh
npx --yes serve game
```

Then open http://localhost:3000 — WASD / arrows to move, Shift to sprint, Space for smoke, C for coin toss, E for vents, F for sabotage.
